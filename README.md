# Manish Sharma Portfolio

Personal portfolio for Manish Sharma, Lead AI Engineer specializing in production LLM, RAG, and agentic AI systems.

## Run locally

This is a dependency-free static site. From the repository root:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

The site can be deployed directly with GitHub Pages by publishing the repository's default branch from the root directory.
